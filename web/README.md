# HateNPity (web)

Минимальный «TikTok-подобный» MVP:

- авторизация (email + пароль)
- загрузка видео
- лента вертикальных видео
- страница видео + комментарии
- спокойный светлый дизайн

Технологии: Next.js (App Router) + Prisma + SQLite + NextAuth (Credentials).

## Локальный запуск

1) Перейдите в папку `web/` и подготовьте env:

```bash
cp .env.example .env
```

В `.env` поменяйте `AUTH_SECRET` на случайную строку (например, через `openssl rand -base64 32`).

2) Установите зависимости:

```bash
npm install
```

3) Примените миграции и создайте SQLite-БД:

```bash
npm run db:migrate
```

4) Запускайте приложение как обычно:

```bash
npm run dev
```

## Где лежат данные

- база данных: `web/dev.db` (локально, не коммитится)
- загруженные видео: `web/var/uploads/videos/` (локально, не коммитится)
